# Д15 · МОНА 5

Интерактивен 3D модел на апартамент Д15 със сгъваема стъклена преграда между кухнята и дневната. Мебелите могат да се местят, завъртат и преоразмеряват. Шкафовете и чекмеджетата се отварят с щракване.

Отвори [редактора](docs/index.html) в браузър с WebGL. В общия изглед W/A/S/D местят камерата, а влаченето завърта гледната точка. В режим „Разходка“ същите клавиши те движат в апартамента. Избери мебел, за да я преместиш с влачене или със стрелките. Промените се пазят в текущия браузър.

## Генериране

С Node.js изпълни `node build.cjs` от основната папка. Командата създава самостоятелния файл `docs/index.html`. GitHub Pages може да го публикува от папка `/docs` на клон `main`.
